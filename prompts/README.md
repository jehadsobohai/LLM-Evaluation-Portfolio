# LLM Evaluation Projects

This folder contains practical prompt engineering and LLM evaluation case studies created by Jehad Soboh.

Each project documents a complete evaluation workflow, including:

- Objective
- Prompt
- Model Responses
- Evaluation Criteria
- Comparative Analysis
- Results
- Lessons Learned
- Skills Demonstrated
- Conclusion

The projects cover multiple domains, including prompt engineering, Arabic language evaluation, medical AI, translation quality assessment, hallucination detection, AI safety, and other LLM evaluation tasks.
