# LLM Evaluation Projects

This directory contains practical LLM evaluation and prompt engineering case studies developed by Jehad Soboh.

Each project applies a structured, transparent, and evidence-based evaluation methodology to assess the performance of Large Language Models (LLMs) across a variety of real-world tasks and domains.

Depending on the project, the documented workflow may include:

- Evaluation Objective
- Evaluation Scope
- Prompt or Task
- Source Text or Input Data (where applicable)
- Model Responses
- Evaluation Criteria and Rubrics
- Evaluation Methodology
- Automatic Evaluation Metrics (where applicable)
- Human-in-the-Loop (HITL) Evaluation (where applicable)
- Comparative Analysis
- Evidence-Based Scoring
- Results and Discussion
- Lessons Learned
- Skills Demonstrated
- Study Limitations
- Conclusion
- References

The projects currently cover areas including:

- Prompt Engineering
- LLM Evaluation
- Translation Quality Evaluation
- Modern Standard Arabic (MSA) Evaluation
- Egyptian Arabic Evaluation
- Medical AI Evaluation
- Comparative Model Analysis
- Human-in-the-Loop (HITL) Evaluation
- Linguistic Quality Assessment

As the portfolio expands, additional projects will explore:

- Standard Benchmark Evaluation (e.g., WMT, FLORES-200, MMLU)
- Automatic Evaluation Metrics (e.g., COMET, BLEU, BERTScore)
- AI Safety Evaluation
- Hallucination Detection
- Reasoning Evaluation
- Benchmark Development
- AI Quality Assurance
