# Evaluation Standards

This directory contains the standards used throughout the **LLM Evaluation Portfolio**.

These standards establish a consistent, transparent, reproducible, and evidence-based methodology for documenting, conducting, and reporting AI evaluation projects.

By following common standards, evaluation projects become:

- Consistent
- Transparent
- Reproducible
- Evidence-based
- Easier to compare across models, tasks, and domains
- Easier to review, maintain, and extend

The standards serve as the foundation for all evaluation projects within this repository.
