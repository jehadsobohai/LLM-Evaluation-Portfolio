# Objective

Evaluate and compare the quality of Modern Standard Arabic (MSA) responses generated by ChatGPT and Google Gemini using a structured evaluation framework.

The evaluation focuses on each model's ability to follow the prompt instructions, produce fluent and grammatically correct Modern Standard Arabic, communicate clearly, and generate encouraging, age-appropriate educational content for a 10-year-old child.

---

## Evaluation Scope

This evaluation examines the ability of Large Language Models to generate educational content in Modern Standard Arabic (MSA) for primary school children.

The assessment focuses on a single educational writing task and compares model performance using a structured human evaluation framework. The evaluation emphasizes instruction following, language quality, audience adaptation, clarity, tone, and cultural appropriateness.

# Prompt

## Role

You are an educational content writer specializing in creating engaging learning materials for children.

## Task

Write a short paragraph in **Modern Standard Arabic (MSA)** explaining the importance of reading to a **10-year-old child**.

### Original Prompt (Arabic)

اشرح أهمية القراءة للأطفال بلغة عربية فصحى بسيطة تناسب طفلًا عمره 10 سنوات.

يجب أن يكون الشرح:

- واضحًا وسهل الفهم.
- أقل من 150 كلمة.
- مشجعًا ومحفزًا.
- خاليًا من الأخطاء اللغوية.
- مناسبًا لطفل في المرحلة الابتدائية.

# Evaluation Criteria

The responses were evaluated using the following criteria:

- Instruction Following
- Arabic Fluency
- Grammar
- Clarity
- Child Appropriateness
- Tone
- Cultural Appropriateness
- Overall Preference

Each criterion is scored on a **5-point scale**, where **5 represents excellent performance**.

Small score differences (for example, **4.5 vs. 5.0**) represent meaningful qualitative distinctions between two high-quality responses rather than large differences in overall capability.

---

# Evaluation Methodology

This case study compares one response generated by each model using a single prompt. Its purpose is to demonstrate a structured LLM evaluation workflow rather than establish a general ranking of model performance.

The evaluation was conducted by a single evaluator using the predefined rubric described above. The scores represent one evaluator's assessment. Future studies could incorporate multiple independent evaluators to measure inter-rater agreement and reduce subjective bias.

Both models were evaluated using the same prompt and evaluation criteria. Performance may vary across prompts, domains, and writing tasks. Therefore, the findings should be interpreted only within the scope of this evaluation.

# Conclusion

This evaluation demonstrates that effective LLM assessment involves more than measuring grammatical accuracy or linguistic sophistication. While ChatGPT produced the stronger formal Arabic response, Gemini better adapted its writing to the intended audience and communication goal. The project highlights the importance of evaluating AI-generated content using multiple criteria—including instruction following, language quality, audience adaptation, clarity, tone, and overall usefulness—rather than relying on a single measure of performance.

Overall, this evaluation demonstrates that high-quality educational content depends not only on grammatical correctness but also on audience adaptation, clarity, engagement, and alignment with the communication goal. Effective LLM evaluation therefore requires multiple complementary criteria rather than relying on linguistic quality alone.

---

# Study Limitations

This evaluation is based on a single prompt and one response from each model. While it demonstrates a structured LLM evaluation methodology, it should not be interpreted as a general ranking of overall model performance.

The assessment was conducted by a single evaluator using a predefined rubric. Subjective criteria such as tone, clarity, and child appropriateness may vary between evaluators. Future work could incorporate multiple independent evaluators to measure inter-rater agreement and further strengthen the reliability of the evaluation.

Model performance may also vary across prompts, domains, writing styles, and future model updates. Consequently, the findings presented here should be interpreted only within the scope of this specific evaluation task.
